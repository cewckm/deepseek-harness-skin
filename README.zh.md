# DSH 自定义皮肤插件

为 DeepSeek Harness 添加本机壁纸和区域颜色设置。右下角的小鲸鱼打开面板，选色、换图和构图即时生效。

初始选择“官方外观”。官方外观保持 DSH 自己的背景、区域配色和主题 token；壁纸、遮罩及区域覆盖均关闭，只保留插件的设置入口。此前的四套内置默认皮肤已从皮肤列表移除，改由用户上传图片创建皮肤；`studio`、`neon`、`sakura`、`film` 四套内部配色基础保留，供自建皮肤继承。旧默认皮肤的选择失效后回到官方外观，已有用户自建皮肤保留。

## 安装

```powershell
git clone https://github.com/cewckm/deepseek-harness-skin
cd deepseek-harness-skin
node .\install.mjs
```

安装到默认 `desktop` profile。刷新页面后，点右下角的黑色小鲸鱼进入设置。

```powershell
node .\install.mjs --profile web   # 安装到其他 profile
node .\install.mjs --dry-run       # 查看将执行的操作
node .\install.mjs --uninstall     # 卸载插件
```

`desktop` profile 由 Electron 应用管理，安装脚本将插件复制到该 profile 的 `node_modules`，并在 `cordis.patch.yml` 写入 `- insert:` 补丁；原补丁文件备份为 `.bak`。

可检查 Host 插件是否加载：

```powershell
curl http://127.0.0.1:19387/deepseek-harness-skin/status
```

路由返回 JSON 表示 Host 已加载。用户上传的图片保存在浏览器本地，不会出现在 Host 的图片资源列表中。

## 添加与管理皮肤

1. 点“＋ 添加皮肤”，填写名称。
2. 在彩色色条选择颜色，或用调色器、`#RRGGBB` 输入精确颜色。
3. 点“选择图片并添加”，选择本机图片。支持 PNG、JPEG、WebP、AVIF、GIF。

新图片默认完整显示、居中、100% 缩放。可继续“上传图片替换”，也可添加多个皮肤，各自保存图片、颜色和取景。删除当前皮肤后回到官方外观；选择官方外观不会删除自建皮肤。

| 设置 | 作用 |
|---|---|
| 工作区颜色 | 独立调整左侧工作区颜色，文字自动适配明暗。每套皮肤分别保存。 |
| 区域颜色 | 分别调整窗口标题栏、对话顶部栏、对话背景、消息气泡、代码块、输入框、右侧工具面板、菜单和弹窗。彩色色条、调色器和十六进制输入可任选。 |
| 颜色浓度 | 0% 透明，100% 纯色，按 1% 步进。降低浓度可透出下方的壁纸。 |
| 文字颜色 | 自动选择明暗，也可手动选色；点“自动”恢复自动文字配色。 |
| 恢复当前区域 / 恢复本皮肤所有区域颜色 | 清除对应区域覆盖，保留图片、取景、左侧工作区颜色及画面效果。 |

半透明背景的自动文字颜色按背景和遮罩估算；复杂壁纸可手动指定文字色。自定义代码块文字颜色会统一代码与标题文字的颜色。区域设置针对 DSH 外壳，嵌入网页、终端和系统文件选择器使用各自的配色。

## 图片位置与画面效果

| 设置 | 作用 |
|---|---|
| 铺满屏幕 / 完整显示 | 铺满可能裁切边缘；完整显示保留整张图片。 |
| 图片缩放 | 在适配尺寸上缩放到 50%–200%；切换适配方式回到 100%。 |
| 横向位置 / 纵向位置 | 调整图片在窗口内的对齐位置。没有裁切且正好铺满的方向不会移动，可先放大或选择完整显示。 |
| 还原位置 | 恢复当前皮肤的居中、完整显示和 100% 缩放。 |
| 立绘浓度 | 仅控制普通透明度，范围 0%–100%。0% 隐藏，100% 显示原图；滤镜为 `none`，不增强对比、饱和度或亮度。 |
| 画面压暗 | 独立的黑色遮罩，0% 不压暗，100% 接近全黑。默认 0%；它不会改变立绘浓度。 |

两根画面效果滑杆均按 1% 步进。旧版超过 100% 的立绘浓度会收敛到 100%。即使立绘浓度是 100%，自选区域背景或画面压暗仍可能遮住图片；想看原图颜色，请将画面压暗设为 0%。

## 本地保存与快捷键

图片以原始文件保存在当前 DSH 页面来源的 IndexedDB；皮肤名称、颜色和取景保存于 localStorage。刷新或重启后保留，不上传到服务器。不同浏览器、profile 或页面来源的数据各自独立，清除该来源的应用数据会清除自定义内容。上传保存失败时保留原图片。

| 操作 | 快捷键 |
|---|---|
| 开关面板 | `Ctrl + Alt + Q`（macOS 为 `Cmd + Alt + Q`） |
| 回到官方外观 | `Ctrl + Alt + 0` |
| 收起面板 | `Esc`，或点击面板外 |

## 开发与验证

```powershell
node .\build.mjs
node .\build.mjs --check
node .\tools\smoke.mjs
node .\install.mjs
```

`src/skins.css`、`src/panel.css`、`assets/skins.json` 和 `assets/whale.svg` 由构建脚本写入 `client.js` 的生成块；其他客户端逻辑直接维护在 `client.js`。日常上传、选色和构图不需要构建。

修改 CSS 或客户端逻辑后，运行构建和安装，再刷新页面。**修改 `index.js`（Host）后必须重启 DSH**，因为 Node 会缓存已导入的模块；重新安装不能代替重启。

`smoke.mjs` 检查客户端加载、面板交互、保存失败、持久化、官方外观和卸载回收等逻辑；它不检查真实 CSS 层叠或窗口渲染。Windows 验收需使用实际 Electron 窗口，核对官方外观、壁纸和区域透明度。`probe-bundle.mjs` 用运行中 DSH 的 HMR 模块图检查客户端是否已加载。

官方外观和卸载都会清除本插件的 token 层、caption 注入与运行样式；图层在官方模式隐藏。DSH 更新后应重新核对窗口结构、区域标记和主题服务兼容性。

## 排错

| 现象 | 处理 |
|---|---|
| 没有小鲸鱼按钮 | 刷新页面，检查 `/deepseek-harness-skin/status` 及安装的 profile。 |
| 看不到图片 | 确认已选择自建皮肤，检查立绘浓度、画面压暗、区域颜色浓度和图片位置；先选完整显示、100% 缩放。 |
| 文字不清晰 | 调整对应区域的颜色浓度或文字颜色，必要时增加少量画面压暗。 |
| 上传失败 | 使用可正常打开的图片，并检查当前页面 IndexedDB 是否可写；原图片会保留。 |
| 改了 CSS 没生效 | 运行 `build.mjs`、`install.mjs` 并刷新。 |
| 改了 Host 没生效 | 重启 DSH。 |
| 想回到官方外观 | 面板选择“官方外观”或按 `Ctrl + Alt + 0`。 |
